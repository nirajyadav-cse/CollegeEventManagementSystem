# Project Statement

## Project Title
College Event Management System

## Problem Statement

Managing college events manually can be difficult when there are many students, events, and registrations. It can lead to duplicate registrations, difficulty in tracking participants, and problems in maintaining event information.
The College Event Management System is developed to provide a simple and organized way to manage students, administrators, college events, and event registrations.

## Proposed Solution

This project provides a menu-driven Java application with three main modules:

1. User Management
2. Event Management
3. Registration Management

The system allows users to add and search students and admins, create and manage events, register students for events, search registrations, and cancel registrations.
The system also uses file handling to store user, event, and registration information so that important data can be maintained between program executions.

## Main Objectives

- Manage student and admin information.
- Manage college event details.
- Register students for events.
- Prevent duplicate registrations.
- Check event capacity before registration.
- Search users, events, and registrations.
- Allow registration cancellation.
- Store application data using files.
- Apply Java Object-Oriented Programming concepts in a practical project.

## Technologies Used

- Java
- Core Java
- Object-Oriented Programming
- ArrayList
- File Handling
- Exception Handling
- Custom Exceptions
- Git and GitHub

## Expected Outcome

The final system provides a simple console-based solution for managing college events and registrations. It demonstrates practical use of Java programming concepts while providing useful functionality for managing event-related information.
